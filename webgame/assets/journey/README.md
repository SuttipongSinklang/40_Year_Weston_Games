# Adventure map artwork

Created with the built-in ImageGen tool on 2026-10-14. The generated raster
art is decorative; the path, fog, milestones, scores, locks and postcards are
interactive HTML/CSS/SVG. The character uses the project's existing GLB model.

- `island-world-long.png`: the current continuous portrait environment; one image covers the entire five-stop map without tiling.
- `island-world.png`: original environment, retained as a source asset and no longer referenced by the map.
- `destinations.png`: 3-column × 4-row atlas. The five-stop map uses the first five cells, revealed only after the corresponding milestone is reached.
