## วิธีเล่น / วิธีรัน

ต้องรันผ่าน HTTP server เท่านั้น (เปิดไฟล์ตรง ๆ จะโหลดโมเดล .glb ไม่ได้):

```bash
cd webgame
python -m http.server 8080
```

## ตรวจสอบ

### การวิ่ง GPS

- หน้าวิ่งจัดตามภาพอ้างอิง: แผนที่ด้านบน เวลาและระยะทางขนาดใหญ่ ปุ่มเริ่มสีเขียวอยู่ในเนื้อหาไม่ทับข้อมูล และสรุปสถิติสามคอลัมน์หลังบันทึก เส้นทางสีแดง จุดเริ่มเขียว จุดล่าสุดแดง
- แผนที่ถนนเปิดอัตโนมัติทุกครั้งที่เข้าหน้าวิ่ง ใช้สีพื้นหลังอ่อนและมุมมองกว้างเพื่อลดรายละเอียดรบกวน ส่วน **แผนที่และเพื่อนร่วมทาง** และปุ่มตั้งค่าถูกนำออกตามคำขอล่าสุด สถิติที่ยังไม่มีข้อมูลจริงแสดง **—**; ความยาวก้าวเป็นค่าที่ตั้ง และจำนวนก้าว/ก้าวต่อนาทีแสดงเฉพาะรอบที่ใช้เซ็นเซอร์นับก้าว
- เปิดเมนู **วิ่ง** → **เริ่มวิ่ง** → อนุญาตตำแหน่ง เวลาจะเริ่มเมื่อ GPS แม่นยำพอ ใช้ **พักการวิ่ง**, **วิ่งต่อ**, **จบและบันทึก** ตามต้องการ
- การวิ่งเก็บใน IndexedDB ของเบราว์เซอร์ก่อน เปิดประวัติเพื่อดูเส้นทาง สปลิต และส่งออก GPX ได้ รีเฟรชแล้วรอบที่ค้างจะเปิดเป็นพัก เพื่อไม่รวมเวลา/ระยะทางช่วงปิดหน้า
- แสดงแผนที่ถนนจาก OpenStreetMap อัตโนมัติเมื่อเข้าหน้าวิ่งตามค่าเริ่มต้นที่ผู้ใช้ขอ ผู้ให้บริการได้รับพื้นที่แผนที่ที่เปิดดู แผนที่เริ่มที่กรุงเทพฯ จนกว่าได้ GPS จริง
- เลือกอนุญาตสำรองแต่ละรอบก่อนส่งพิกัด เวลา ระยะทางขึ้น Supabase ตาราง `weston_runs` มี RLS เฉพาะเจ้าของ ติดตั้งแล้วด้วย migration `weston_private_running_history` จากไฟล์ `supabase/running.sql` Anonymous Sign-Ins ยังต้องเปิดก่อนสำรองได้
- **GPS บนโทรศัพท์ต้องใช้ HTTPS** การเปิดผ่าน `http://192.168.x.x:8080` เล่นเกมได้ แต่เบราว์เซอร์ไม่ให้ใช้ GPS; `http://localhost:8080` บนคอมเป็นข้อยกเว้นสำหรับพัฒนา
- เปิดหน้าเว็บและหน้าจอไว้ขณะวิ่ง เมื่อสลับแอป ออกจากหน้าวิ่ง หรือปิดหน้าจอ จะพักอัตโนมัติ โหมดเว็บนี้ยังไม่ใช่การติดตามเบื้องหลังแบบแอป native
- ไม่ผูกการวิ่งกับ XP จากการแตะตัวละคร ตัวเลขสุขภาพตัวอย่างเดิมไม่ได้ถูกเปลี่ยนให้เป็นข้อมูลจาก GPS

แผนที่ใช้ Leaflet **1.9.4** แบบ vendored ใน `assets/vendor/leaflet/dist/` พร้อม LICENSE ไม่ต้องใช้ API key สำหรับแผนที่ นโยบายบริการ: [OSM tile usage](https://operations.osmfoundation.org/policies/tiles/) ข้อกำหนด GPS: [MDN watchPosition](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation/watchPosition)

### Android / iPhone และการล็อกจอ

โค้ดแอปใน `../mobile` เพิ่ม native GPS recorder ที่เก็บตำแหน่งต่อขณะ WebView ซ่อน/ล็อกจอ และอ่านกลับเข้าหน้าวิ่งเดียวกัน ใช้ได้เฉพาะแอปที่ build พร้อมปลั๊กอิน ไม่ใช่หน้าเว็บ localhost หรือ PWA เว็บเดิมยังพักเมื่อซ่อนจอ ดูขั้นตอน build และข้อจำกัดใน [mobile/README.md](../mobile/README.md) ขณะนี้ sync โปรเจกต์สำเร็จและทดสอบข้อมูลจำลองแล้ว แต่ยังไม่มี APK/IPA ที่ build สำเร็จและยังไม่ผ่านการทดสอบโทรศัพท์จริง

ติดตั้ง dependency ทดสอบเฉพาะครั้งแรก แล้วรันชุดทดสอบทั้งหมด:

```powershell
npm ci --prefix tests
npm test --prefix tests
```

การทดสอบ GPS ใช้ตำแหน่งสังเคราะห์ ไม่มีการขอตำแหน่งหรือส่งพิกัดจริงจากเครื่องทดสอบ SQL `tests/running-database.sql` ตรวจสิทธิ์บนฐานข้อมูลจริงภายใน transaction ที่ rollback เสมอ

```bash
node --experimental-vm-modules --test tests/data.test.mjs tests/progress.test.mjs
```

รันจากโฟลเดอร์ราก `../` SQL ใน `../tests/database.sql` ทดสอบสิทธิ์ผู้เล่น การนับคะแนน และการส่งซ้ำภายใน transaction แล้ว rollback fixtures ทั้งหมด
# แผนที่นักวิ่งสด

หน้าวิ่งปัจจุบันนำส่วนเพื่อนร่วมทางและตัวเลือกแชร์ออกแล้ว จึงไม่เปิดการติดตามนักวิ่งคนอื่นหรือแชร์ตำแหน่งจากหน้านี้ โมดูล Realtime เดิมและข้อมูลในฐานข้อมูลยังคงอยู่โดยไม่ได้ถูกลบ


# ลู่วิ่งที่บ้าน

หน้าวิ่ง → **ลู่วิ่งที่บ้าน** → **เริ่มวิ่ง** ระบบจับก้าวอัตโนมัติและใช้ความยาวต่อก้าวเริ่มต้น 0.75 ม. ทุกครั้ง ไม่ต้องตั้งค่าหรือกรอกระยะทาง ระยะทางประมาณ = จำนวนก้าว × 0.75 ม. แล้วคำนวณเพซจากเวลาไม่รวมพัก ค่านี้เป็นค่าเริ่มต้นของแอป ไม่ใช่ค่าความยาวก้าวที่วัดจากแต่ละคน ต้องพกโทรศัพท์ที่เอวหรือกระเป๋ากางเกงเพื่อจับก้าวได้

Android native ใช้ step detector/counter และสิทธิ์ Activity Recognition; iPhone native ใช้ CMPedometer และ Motion & Fitness; เว็บใช้ DeviceMotion ซึ่งต้อง HTTPS/localhost และเบราว์เซอร์ที่รองรับ หากไม่มีเซ็นเซอร์/ปฏิเสธสิทธิ์/ไม่ส่งข้อมูล จะไม่สร้างระยะทางหลอก ยังไม่ได้ทดสอบโทรศัพท์จริงหรือความแม่นยำการนับก้าว/ความยาวก้าว หากวางโทรศัพท์บนหน้าจอลู่วิ่ง จะไม่วัดการเคลื่อนไหวร่างกายได้

เฉพาะรอบกรอกระยะทางเดิมที่ยังไม่จบ จะมีช่องกรอกค่าจากเครื่องเพื่อบันทึกรอบนั้นให้เสร็จ รอบใหม่ใช้จับก้าวอัตโนมัติ ระบบแยกแหล่งระยะทางในประวัติและสำรองส่วนตัว ไม่มี GPS เส้นทาง หรือเวลาแยกแต่ละกิโลเมตร โค้ดรุ่นนี้ยังไม่อ่าน Bluetooth ลู่วิ่ง/นาฬิกา

เว็บในเบราว์เซอร์ต้องเปิดหน้านี้ไว้และพักเมื่อซ่อน/ล็อกจอ ส่วนแอป native ใช้ระบบบันทึกต่อขณะล็อกจอตามรายละเอียดด้านล่าง การสำรองออนไลน์ใช้ `supabase/treadmill.sql` และ `supabase/phone-steps.sql` ซึ่งติดตั้งแล้ว และยังขึ้นกับการเปิด Anonymous Sign-Ins

## ลู่วิ่งเมื่อล็อกจอ (แอป native)

โหมดลู่ในแอป Android/iPhone ใช้ตัวบันทึก native แยกจาก GPS และไม่พักเมื่อซ่อนหน้าหรือเปลี่ยนเมนู Android มี health foreground service พร้อมแจ้งเตือน/ปุ่มพัก และ CPU wake lock (หน้าจอยังดับได้ แต่ใช้แบตเตอรี่เพิ่ม); iPhone ใช้ CMPedometer เก็บก้าวในระบบและรวมยอดช่วงที่วิ่งเมื่อกลับเข้าแอป เวลาใช้ช่วงเริ่ม/พักจริง ไม่พึ่ง JavaScript ที่ถูกพัก ก้าวช่วงกดพักไม่รวม ระยะทางยังประมาณจากก้าว×ความยาวก้าว และต้องพกโทรศัพท์ติดตัว

ต้อง build/ติดตั้งแอป native ก่อน เว็บ/PWA ยังพักเมื่อล็อกจอ ขณะนี้ยังไม่มี APK/IPA และยังไม่ได้ตรวจบนโทรศัพท์จริง การบังคับปิดแอป/OS ฆ่า process อาจหยุดการบันทึกและกู้เป็นพัก ณ checkpoint ล่าสุด รอบเดิมที่ค้างใน IndexedDB ต้องจบและบันทึกก่อนเริ่ม native รอบใหม่

## ผลแก้ระบบวิ่ง 2026-10-09

จบแล้วบันทึกออนไลน์ส่วนตัวอัตโนมัติ ไม่มีปุ่ม GPX/สำรองออนไลน์ ข้อมูลรอส่งอยู่ในคิวเมื่อเน็ตขาด; รอการยืนยันจากเซิร์ฟเวอร์ก่อนขึ้นว่าบันทึกแล้ว จุด P1/R1 ตามครั้งที่พัก/วิ่งต่อแสดงในแผนที่และรายละเอียด แก้ความสูง Leaflet ในหน้าจบให้เห็นเส้นทางจริง ประวัติเดิมที่ไม่ได้เลือกส่งออนไลน์ยังอยู่ในเครื่อง
