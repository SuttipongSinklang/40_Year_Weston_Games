# Weston Fit Quest 🎮

เว็บเกมฟิตเนสสำหรับมือถือ (mockup) — สร้างจากรูปอ้างอิง `Home.png` และ `Leader Board Person.png`
ตัวละครกลางจอเป็นโมเดล 3D "พี่ชาญ_Fat" ยืนนิ่ง ไม่มี Animation (ไฟล์ต้นฉบับ `พี่ชาญ_Fat.glb`)

## วิธีเล่น / วิธีรัน

ต้องรันผ่าน HTTP server เท่านั้น (เปิดไฟล์ตรง ๆ จะโหลดโมเดล .glb ไม่ได้):

```bash
cd webgame
python -m http.server 8080
```

แล้วเปิด http://localhost:8080 บนมือถือหรือเบราว์เซอร์
(บนเครื่องเดียวกันใช้ IP เครื่องแทน localhost เช่น http://192.168.x.x:8080)

## ฟีเจอร์

| หน้า | คำอธิบาย |
|---|---|
| หน้าหลัก | โมเดล 3D + ฉากสวน, HUD โปรไฟล์/XP, Day Streak, การ์ดสถิติ 4 ใบ, การ์ดภารกิจ |
| ถ้วยรางวัล | Leaderboard บุคคล/ทีม พร้อม crown อันดับ 1-3 และแถว "คุณ" |
| เป้าหมาย | Ring progress 62% + รายการเป้าหมายรายวัน |
| ปฏิทิน | ปฏิทินตุลาคม 2026 พร้อมสรุปเดือน |
| สังคม | รายชื่อเพื่อน + feed กิจกรรม กด like ได้ |

## อินเทอร์แอ็กชันในเกม

- **แตะตัวละคร** → นับภารกิจ +1 (+1 💪 ลอยขึ้น, XP เพิ่ม, XP เต็ม → เลเวลอัป)
- **ลากนิ้วบนฉาก** → หมุนตัวละคร (ปล่อยไว้ 3 วิ จะหมุนเองช้า ๆ)
- **ครบภารกิจ 5/5** → ขึ้นภารกิจใหม่อัตโนมัติ

## โครงสร้างไฟล์

```
webgame/
├── index.html          # โครงหน้าเว็บทั้ง 5 หน้า + bottom nav
├── css/style.css       # สไตล์ mockup (โทนสีตามรูปอ้างอิง)
├── js/main.js          # Three.js + logic เกม + ข้อมูล mockup
└── assets/
    └── chan_fat.glb     # โมเดล 3D พี่ชาญ_Fat (สำเนาจากไฟล์ พี่ชาญ_Fat.glb)
```

## หมายเหตุ

- ทุกตัวเลข/รายชื่อเป็น **mockup** (ยังไม่มี backend) — เชื่อมมาโครได้ที่ `js/main.js` ส่วน data
- Three.js โหลดจาก CDN (jsdelivr) ต้องต่อเน็ตครั้งแรก
- โมเดล .glb ~8MB ครั้งแรกจะโหลดสักครู่
